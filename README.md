# nmr-data-analysis
A collection of Fortran programs for scientific data processing, including time-unit conversion for solid-state NMR data.


## Fortran Program: Time Conversion

### Overview

This program converts time values from seconds to milliseconds in a data file.

### Source Code

`Time converter (s to ms).f`

### Conversion

The program multiplies the time values by 1000 to convert seconds into milliseconds.

### Purpose

This program demonstrates scientific programming and data processing for solid-state NMR applications.
